# 🧠 Synthetic Brain: LLM Architecture
An exploratory project focused on building a large-scale neural architecture optimized for **NVIDIA Hopper (H100)** compute.

## 🚀 Vision
To design a "Copilot-class" intelligence from scratch, focusing on hardware-software co-design and memory-efficient attention mechanisms.

## 🛠 Tech Stack
- **Hardware Target:** NVIDIA H100 / B200 Tensor Core GPUs
- **Framework:** PyTorch / NVIDIA Apex
- **Optimization:** DeepSpeed & FlashAttention-2

## 📖 What I'm Learning
- Distributed training on multi-GPU clusters.
- Cost-optimization for "from-scratch" pre-training.
- CUDA kernel optimization for code-specialized LLMs.
